This template demonstrates how a multi-file dissertation can be organized and compiled in LaTeX. The document separates front matter, chapters, figures, references, appendices, and biographical information into focused source files while retaining a single compilation entry point. Its example chapters illustrate common scholarly elements, including citations, equations, tables, algorithms, theorems, cross-references, external graphics, TikZ diagrams, and PGFPlots charts. The text and numerical values are intentionally generic and should be replaced with the student's approved dissertation content. By providing a complete working structure, the template helps writers concentrate on research and argument while LaTeX manages numbering, navigation, and consistent formatting.
